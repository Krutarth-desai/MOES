# Sample Data Directory

This directory stores representative sample forecast datasets and observation records for development, verification, and testing.

### Sample Files Overview:
- `stations_india.json`: Curated meteorological observatories across India representing distinct agro-climatic zones (Himalayan, Coastal, Peninsular, Indo-Gangetic Plains, Arid West).
- `sample_forecast_snapshot.json`: Standardized multi-model forecast slice (GFS, ECMWF, GraphCast, Pangu) with corresponding observation ground truth for verification tests.
